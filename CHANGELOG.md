# Changelog

All notable changes to **Stride** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-06

### Added

- Initial release of Stride.
- Goal management with unlimited hierarchical sub-goals (Outcome and Target goals).
- KPI tracking with bidirectional progress (works for both increasing and decreasing targets).
- KPI milestones and a "change target" history.
- Habit tracking with interval-based frequency ("every X hours / days / weeks"),
  streaks, and habit-to-goal linking with importance levels.
- Measured habits with fractional daily progress and partial-progress streaks.
- KPI analytics for both goals and habits (value-over-time charts + stats).
- Calendar views: Day, Week, Month, and Year, each with active-goal columns and tag filters.
- Goals tab with search, tag filters, a depth-limited goal tree, and a full habit list.
- SMART goal-setting in-app guide.
- Local OS notifications with automatic scheduling on create/edit/delete and app start,
  plus a "send test notification" button in Settings.
- Local backup & restore (JSON export/import).
- Cascading deletes (deleting a parent goal removes its sub-tree and linked habits/data).
- Dark / light theming.

### Known Issues

- None.
